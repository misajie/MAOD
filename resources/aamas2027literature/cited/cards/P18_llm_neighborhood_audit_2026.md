# P18 Do LLMs Know Your Neighborhood? Auditing LLM Priors for Neighborhood-Level Mobility

- **作者**：见 arXiv:2609.00345 作者表
- **年份 / 阵地**：2026 / arXiv:2609.00345
- **线**：短时移动（LLM 先验审计 / 公平）

- **原文存档**：PDF `pdf/P18_llm_neighborhood.pdf`；页面/文本 `html/P18_arxiv.html ；txt/P18.txt`；远程 https://arxiv.org/abs/2609.00345。总清单见 `literature/sources/SOURCES.md`。

## 科学问题

零样本 LLM 能不能根据城市语境推断街区尺度的加总流动？推断若对，是结构真的被“理解”了，还是一套跨城不变的粗糙先验？对受保护群体属性是否对称？

## RQs 与实验设计

1. 四个美国大都市，Cuebiq 匿名数据构造点、轨迹、时间三类街区结果。
2. 配上社会人口与建成环境预测变量。
3. 零样本 LLM vs 监督基线。
4. 方向对齐：LLM 隐含的变量效应 vs OLS / Jonckheere–Terpstra 经验趋势。

## 评估指标

- 平均准确率：监督 0.580 vs 最好 LLM 0.435
- 分结果类型（空间范围最好预测，但 LLM–基线缺口也最大）
- 跨城、跨结果的先验稳定性
- 受保护群体变量的不对称符号

## 模型类别

零样本 LLM 审计，对照监督模型与经典统计趋势检验。不是新预测器竞赛。

## 数据清单

- Cuebiq 匿名移动
- 美国 Census Block Group
- 四个都市的社会人口与建成环境

## 主要发现

- LLM 能部分回收加总模式，但明显弱于监督模型。
- 先验跨城几乎不变，像刻板印象，不像地方结构。
- 对受保护群体预测变量处理不对称。
- **不能把 LLM 当结构真实的世界模型**，必须做实证对齐审计。

## 现实意义

规划/公共健康若直接拿零样本 LLM 生成街区流动，会把预训练语料里的社会偏见写进地图。

## 与本项目关联

本项目预登记分区包含性别、年龄，明确不做族群标题。这篇审计说明：即使用 LLM 补标签或生成对照矩阵，也必须把 Condition S 的 CPC 按人口属性拆开看，否则“看起来像”可能只是先验。
